Version 1.0 | Optimized for LLM Context Window Efficiency
 Quick Overview
This guide walks you through a two-stage workflow  to generate 250+ accurate
Q&A pairs for the U.S. Army website using optimized LLM prompts:
Stage 1: Question Generation  (15-20 min) → 250 questions
Stage 2: Answer Generation  (30-40 min, in 10 batches) → 4 answer
variants per question
 Total Time to 250 Q&A Pairs: 45-60 minutes

Step 1: Prepare Your URLs

• https://www.goarmy.com/how-to-join/steps/recruiter

• https://www.goarmy.com/how-to-join/requirements
• https://www.goarmy.com/how-to-join/requirements/fitness
Step 2: Copy the Question Generator Prompt
Action:  Open question-generator-prompt.md  (or .docx) and copy the
ENTIRE content starting from "SYSTEM PROMPT: U.S. Army Question
Generator" through to the end.
Do NOT copy:  Metadata, file headers, or explanatory text before the system
prompt.
Step 3: Paste Prompt into Your LLM
Action:  Open your LLM interface (ChatGPT, Claude, etc.) and paste the
entire Question Generator Prompt into a new conversation.

for input.

⚙ BEST PRACTICES & OPTIMIZATION TIPS
1. Context Window Management
 DO:  Process 25 questions per batch (as designed)
 DON'T:  Try to process all 250 at once (will exceed LLM context limits)
 DO:  Use separate LLM conversations for Question Gen and Answer Gen
 DON'T:  Mix prompts in the same conversation
2. Quality Assurance
Check QA Validation Columns:  Look for "⚠" warnings; review those
answers for accuracy
Corpus Alignment:  Questions flagged as "Corpus mismatch" may need
review against live goarmy.com
Character Length:  Each answer should be 400-500 characters. Flagged
ones outside this range may need revision•

3. Processing Speed
Faster Processing:  Use faster LLM models (e.g., GPT-4 Turbo instead of
GPT-4) for batches
Parallel Batches:  If using multiple LLM accounts, run 2-3 batches in parallel
(but keep conversation history)
Time Tracking:  Average 4-5 minutes per batch; if longer, check your LLM's
load/speed
4. Customization Options
If you want to modify behavior, edit the prompts before using:
Change target from 250 to 300 questions:  Edit "target_per_run" in
Question Generator
Focus on specific personas:  Modify "personas" section to limit Prospect/
Career Seeker/etc.
Adjust answer tone spectrum:  In Answer Generator, modify "Very Direct/
Direct/Somewhat Direct/Indirect" rules
 TROUBLESHOOTING GUIDE
Issue 1: LLM Produces Fewer Than 250 Questions
Cause:  Insufficient content on provided URLs for 250 unique questions.
Solution:
Check the "Estimated unique questions possible" range from the output
If range is 180-220, accept the lower count (better quality than forced filler
questions)
Alternatively, add more URLs to expand content scope
Issue 2: Questions Don't Match Answer Table Structure
Cause:  Accidental reformatting when copying question table.
Solution:
Re-copy the exact question table from Stage 1 output
Use "Copy as Plain T ext" if your editor offers it
Verify headers match: T opic | Persona | T one | Question•

Issue 3: Answer Generator Returns Warning "Table not
recognized"
Cause:  Markdown table format corrupted or incorrect headers.
Solution:
Ensure table has correct headers separated by | (pipe) characters
Verify no extra rows or blank lines in the middle of the table
Copy-paste from a fresh question generator output
Issue 4: QA Validation Shows "⚠ Not in corpus" for Many
Answers
Cause:  The corpus file doesn't contain all topics covered by URLs.
Solution:
This is normal  if corpus file is outdated
Review answers with live site validation (URLs are still valid)
Update corpus file if possible to match current goarmy.com content
Issue 5: Processing Takes Longer Than Expected
Cause:  LLM service slow, model overloaded, or network latency.
Solution:
Try during off-peak hours (early morning or late night)
Use a faster model option if available
Check your LLM service status page for outages
Try a different LLM provider as a backup
Issue 6: Answer Variants Are Too Similar
Cause:  LLM produced paraphrases instead of distinct angles.
Solution:
This may indicate the question is straightforward with limited answer
variations
Manually review and revise similar answers
For future batches, include a custom note: "Ensure answer variants use
clearly different angles"•

 ADVANCED: PARALLEL BATCH PROCESSING
If you have multiple LLM accounts or want to speed up:
Open 2-3 separate LLM conversations, each with the Answer Generator
Prompt
Submit batches to each in parallel (Batch 1 to Conversation A, Batch 2 to
Conversation B, Batch 3 to Conversation C)
As each batch completes, move to the next batch in order
Collect all completed batches and consolidate into master file
Speed Improvement:  40-50 minutes → 15-20 minutes for all 10 batches
